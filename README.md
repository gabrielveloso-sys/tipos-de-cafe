## O que foi feito (Atividade 1)

- Página inicial com HTML semântico e CSS externo, sem JavaScript
- `lang="pt-BR"`, `meta viewport`, `title` próprio e link "Pular para o conteúdo"
- Landmarks: `header`, `nav`, `main`, `aside` e `footer` (com `address`)
- Hierarquia de títulos sem saltos: um `h1`, `h2` nas seções e `h3` nos artigos
- 3 `article` (Espresso, Cappuccino, Café coado), cada um com `figure` + `figcaption`, `alt`, `width` e `height`
- Tabela comparativa com `caption`, `thead`, `tbody` e `th` com `scope`
- Formulário de contato com `label` em todos os campos, `type` corretos e `fieldset`/`legend`
- Uso de `time`, `address`, `strong` e `em`
- Layout responsivo (uma coluna em telas até 700px)
